# TaskFlow API

A FastAPI-based REST API for task management with user authentication. 
Built as part of my Python Backend Developer portfolio.

## 🚀 Tech Stack
- **Backend**: Python, FastAPI
- **Database**: MySQL + SQLAlchemy ORM
- **Auth**: JWT Bearer Tokens
- **Validation**: Pydantic Schemas
- **Server**: Uvicorn

## ✨ Features
- User Registration and Login with JWT
- Full CRUD for Tasks: Create, Read, Update, Delete
- Task fields: title, description, due_date, priority, status
- Protected routes - only logged-in users can access their tasks
- API Documentation with Swagger UI
